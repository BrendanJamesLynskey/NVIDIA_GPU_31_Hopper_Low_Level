# Inside Hopper — FP8, TMA, Thread-Block Clusters, NVLink 4

A low-level deep dive into NVIDIA's 2022 Hopper architecture: the GH100 die at TSMC 4N, the Hopper SM with 4th-generation tensor cores delivering native FP8 (E4M3, E5M2) at 1979 TFLOPS dense / 3958 sparse, the warp-group MMA (WGMMA) instruction, the Tensor Memory Accelerator (TMA), thread-block clusters and distributed shared memory, DPX instructions for dynamic programming, HBM3 / HBM3e, NVLink 4 at 900 GB/s, NVSwitch 3 in HGX H100, the GH200 Grace-Hopper superchip, and the H800 / H20 export variants. Includes an interactive Hopper SKU picker.
